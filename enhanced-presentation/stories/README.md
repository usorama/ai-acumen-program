## Design System Foundation

### Ultra-Clean 3-Color Palette
- **Background**: `#000000` (Pure black)
- **Cards**: `#0F0F0F` (95% black, barely visible)
- **Text**: `#CCCCCC` (Light gray primary)
- **Accent**: `#00FF94` (Bright mint green)

### Typography Hierarchy
- **Font Family**: Inter (300, 400, 500, 600, 700, 800)
- **Hero**: 4rem (64px) for main titles
- **Title**: 2.5rem (40px) for section headers
- **Heading**: 1.75rem (28px) for subsections
- **Large**: 1.25rem (20px) for emphasis
- **Body**: 1rem (16px) for regular content
- **Small**: 0.875rem (14px) for details

### Spacing System (8px Grid)
- **XS**: 0.5rem (8px)
- **SM**: 1rem (16px)
- **MD**: 1.5rem (24px)
- **LG**: 2rem (32px)
- **XL**: 3rem (48px)
- **2XL**: 4rem (64px)
- **3XL**: 6rem (96px)
